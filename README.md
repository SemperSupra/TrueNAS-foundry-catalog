# TrueNAS Foundry Catalog

Standalone product for read-only discovery of pinned TrueNAS official Apps, Foundry and registered compatible third-party sources, with human browser, CLI/API and agent consumers. This project consumes the generic Foundry source identity and read API contracts; it does not implement a second inventory, scheduler, actuator or TrueNAS lifecycle engine.

**Status: source-only candidate, not a released or install-qualified OCI image.** Installation, upgrade and adoption require separately qualified Foundry ownership/target controls. Physical TrueNAS deployment remains HOLD.
